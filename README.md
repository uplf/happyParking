# HappyParking - 2022年电赛C题《自动泊车电动车》系统实现
本项目是为 2022 年全国大学生电子设计竞赛（TI杯）C题——自动泊车电动车设计的嵌入式控制系统。项目集成了机器视觉、PID闭环控制、姿态融合与路径规划等核心技术，实现了电动车在预设场地内的自动寻迹、目标库位识别及精准入库泊车功能。

## 项目概述
本系统解决复杂场地环境下的自动驾驶与自动泊车问题。车辆通过视觉传感器感知地面引导线与库位标识，结合 IMU 姿态传感器和轮式编码器，在多传感器融合的架构下完成预定任务。

## 核心任务说明
- 自动寻迹：沿黑色引导线平稳行驶，支持直线与弧线路径。

- 目标库位识别：实时监测库位标志点（方块/色块），支持指定库位的动态定位。

- 精准泊车：根据识别到的库位编号，执行倒车入库或侧方泊车动作，确保车体完全进入且不压线。

## 系统架构与控制逻辑
项目代码由 STM32（底层控制）与 OpenMV（视觉感知）两部分组成。

1. 视觉感知层 (OpenMV)
- 寻迹逻辑：在 OpenMV1巡线.py 中，采用图像阈值分割与区域加权算法，实时计算引导线相对于图像中心的偏移量（Error），通过串口（UART）上报。

- 目标识别：在 计数，方块.py 中，利用形态学处理识别赛道旁的特定标志块，实现库位的精准计数，解决泊车位定位问题。

- 环境适配：针对光照变化，脚本支持动态阈值调整，提升了感知系统的鲁棒性。

2. 底层控制层 (STM32)
底层代码基于自研的 STM32 小车驱动模板开发，核心控制逻辑集中在 main.c 与 drive.c 中：

状态机管理：main.c 中维护了一个有限状态机（FSM），根据任务阶段在“寻迹行驶”、“库位确认”、“泊车动作执行”及“停止”状态间无缝切换。

双环 PID 控制:

- 外环（视觉环）：根据 OpenMV 返回的偏移量进行位置环 PID 计算，输出转向修正量。

- 内环（速度环）：结合编码器反馈，通过 drive.c 驱动电机实现左右轮差速闭环，保证行驶轨迹的平滑。

## 硬件资源
主控模块：STM32F103C8T6

视觉模块：OpenMV Cam

姿态感知：MPU6050 / WIT 维特智能姿态传感器

动力执行：直流减速电机 + 增量式编码器 + TB6612FNG 驱动


## 文件结构说明
```
├── OpenMV/              # 视觉处理脚本 (MicroPython)
│   ├── OpenMV1巡线.py    # 寻迹感知逻辑
│   └── 计数，方块.py     # 库位识别逻辑
├── STM32/               # 嵌入式底层代码 (C)
│   ├── User/
│   │   └── main.c       # 系统控制中枢与任务调度
│   ├── Hardware/
│   │   ├── drive.c      # 电机驱动与差速逻辑
│   │   ├── openMV.c     # 视觉通信协议封装
│   │   └── mpu6050.c    # IMU 驱动与数据采集
│   └── System/          # 中断管理与基础外设
└── PCB.zip/             # 硬件设计图纸与 Gerber 文件
注：STM32 文件夹由通用小车模板演化而来，部分冗余文件（如未调用的外设驱动）已保留以备后续扩展，核心逻辑请以 User 及 Hardware 目录下的关键文件为准。
```
